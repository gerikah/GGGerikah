# Technology logo sources

The toolbox uses locally hosted brand marks from the [Devicon project](https://github.com/devicons/devicon), pinned to commit [`6a37858047b0e8d9c9c0e68f4a071fc410652e89`](https://github.com/devicons/devicon/tree/6a37858047b0e8d9c9c0e68f4a071fc410652e89), dated 11 October 2026. The files were downloaded on 14 October 2026 and copied without vector or color edits.

The toolbox names and their associated projects remain derived from published CMS content. These assets cover the nine documented tool labels. HTML and CSS display as HTML5 and CSS3, and Node/npm displays as separate Node.js and npm entries with the same project associations. No Figma entry is added because the existing project content does not list it. Future CMS tool names without a matching mark remain text links.

Most selected files are Devicon's single-color `plain` glyph variants. Vercel's original mark is already a single triangle; npm's wordmark identifies the second part of Node/npm. Site CSS applies a monochrome presentation without changing the SVG geometry. The images have empty alternative text and are hidden from assistive technology because their adjacent text supplies the technology name. Each entry links to its first associated case study, visibly names that project, and lists all associated project titles in its tooltip. Next.js serves the local SVGs directly with `unoptimized`; no icon CDN or extra runtime package is required.
